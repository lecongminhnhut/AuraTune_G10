Candidate module/test filenames are contingent on accepted source/layout decisions; record approved relocation in the gate ledger before execution. Folder migration reference means only an accepted necessary delta or recorded no-DDL rationale.
- Only this Tasks file is created now. Future preparation/evidence/source/test outputs below are not created in this pass. No protected source document, peer feature, application code or Git branch is modified.
- [P] permits separate file-writing after prerequisites/gates. It does not permit concurrent shared DB resets, race fixtures, live media changes, shared source edits or replay as another principal. Default actual test execution is serialized unless approved isolated environments exist.
