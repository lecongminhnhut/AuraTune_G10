- Each task has sequential ID, optional [P], a story label in story phases, concrete deliverable/path, direct predecessors and traceability. GATED tasks additionally state cluster IDs, closure evidence and shared architecture.
- RUNNABLE means evidence/proposals/scenario writing with current sources, **without** choosing unresolved scope/formulas/schema/API/provider or obtaining approval. Missing evidence can be recorded; proposals cannot self-approve.

- Gate evidence is staged: accepted applicable design/interface/path decisions permit authoring, working permitted fixtures/runner permit execution, actual results permit acceptance. A test's own future passing result is never a prerequisite to writing it.
- Repository-relative future module/test/preparation/evidence paths are proposed work locations, not existing files or approved wire/schema. Accepted relocation must be recorded before dependent work. No table/event/aggregate migration, new job/cache/service infrastructure or retention policy is selected.
- Only this Tasks document is created now. Future outputs below are not created; protected specifications/planning/UI, peers, application code and branches are unchanged.
- [P] means separate file-writing after prerequisites/gates. Actual shared DB/media/session resets, race tests, shared source edits and browser execution serialize unless accepted isolated environments exist.
- V01–V16 refer to the [quickstart acceptance matrix](./quickstart.md#planned-acceptance-scenarios). P01–P13 are the original [research decisions](./research.md#decision-register); E01–E16 map existing Group 110 clusters, not new decisions.
- M1–M4/H1–H4 are [dictionary labels](./data-model.md#metric-dictionary), **not DTO field names**. No fifth KPI, follower count, user follow-list summation, chart, export or tracking feature is added.
- No date/month/range selector and no automatic/periodic/realtime refresh. No stale current values after failure or lost Admin. Successful per-metric calculation time is backend-derived and displayed Asia/Ho_Chi_Minh (UTC+7), never browser render time.
- No silent conditional skip: T023–T026/T029/T030 and T054–T056 remain gated while scope conflicts exist.
