# AuraTune Project Repository

_Performed by: [Name], Reviewed by: [Name], Edited by: [Name]_

AuraTune is a web application designed for music streaming and community connection, featuring an advanced AI Conversational Agent. This repository contains both the source code and the official documentation for the project.

## Repository Structure

```text
auratune/
├── docs/                             ← All non-code project documentation
│   ├── ai-log/                       ← AI usage logs and guidelines
│   │   └── README.md
│   ├── analysis-and-design/          ← System architecture, UI/UX, and API docs
│   │   └── api-contract.md
│   ├── management/                   ← Team rules and workflows
│   │   ├── git-workflow.md
│   │   └── team-contract.md
│   ├── proposal/                     ← Original project proposal & survey
│   ├── requirements/                 ← Vision document and use cases
│   ├── test/                         ← Test plans, test cases
│   └── weekly-reports/               ← Weekly progress reports and Jira screenshots
│
├── specs/                            ← Spec Kit specifications and tasks
│
├── src/                              ← Source code
│   ├── ai-service/                   ← AI Conversational Agent microservice
│   ├── backend/                      ← Backend API and server logic
│   ├── database/                     ← Database schemas and initialization scripts
│   └── frontend/                     ← Web application frontend
│
├── .gitignore                        ← Ignored files and environment variables
└── README.md                         ← Project root index
```
