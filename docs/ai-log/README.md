# AI Usage Guidelines

\_Performed by: Nhựt, Reviewed by: [], Edited by: []

This directory contains the rules and logs for Artificial Intelligence (AI) tool usage in the AuraTune project. According to the course guidelines, every instance of AI assistance must be logged to ensure transparency, fairness, and academic integrity.

## 1. File Assignment

Logs are recorded in 5 specific files, each assigned to a team member (from A to E). Whenever a member uses AI for a task, they must append a new log entry into their respective file:

- `AI_log_1.md`: Member A (Nhựt)
- `AI_log_2.md`: Member B (Khoa)
- `AI_log_3.md`: Member C (Đăng)
- `AI_log_4.md`: Member D (Hoàng)
- `AI_log_5.md`: Member E (Huy)

## 2. Core Principles

- **Security:** Never include real personal data, database credentials, API keys, or secret tokens in your prompts.
- **Accountability:** You must be able to thoroughly explain every line of code or text you submit that was generated or assisted by AI.
- **No Blind Copying:** Do not directly copy AI-generated content without understanding, testing, and modifying it.
- **Transparency:** Clearly state which tools were used and for what purpose, providing exact prompts and validation methods.
