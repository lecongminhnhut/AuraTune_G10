## Asset Rules

- Use descriptive filenames that include the UC ID and flow identifier.
- Keep image files in this directory unless the group has an agreed shared-asset convention.
- Reused assets must retain attribution to their source path.
- Do not label a mockup or wireframe as an implemented UI.
- Check every relative image path by opening the Markdown preview after cloning the repository.
- Include all distinct screens/states needed to understand the Basic Flow and applicable Alternative Flows.
