## Boundaries
Performed by: Thái Hoàng | Reviewed by: Group 10 team | Edited by: Lê Công Minh Nhựt

Only a current authorized Administrator may perform management actions. Personal listening analysis belongs to Groups 070/100; Artist Studio remains Artist-only. Platform overview is read-only and does not authorize reset or mutation.

The owner selected newer administration behavior on 2026-11-20: direct ban/unban with the defined default reason when a custom reason is absent; direct track removal/restoration with preserved history. This supplements the unchanged feature sources; it does not establish application completion.
