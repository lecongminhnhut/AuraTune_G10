## 3. Work Schedule and Deadlines

_Performed by: [Lê Công Minh Nhựt], Reviewed by: [Mai Đăng Khoa, Thái Hoàng, Nguyễn Khánh Đăng, Nguyễn Thanh Huy], Edited by: [Lê Công Minh Nhựt]_

- **Task Assignment Schedule:** Main tasks are officially assigned every **Monday**. If necessary, additional secondary tasks may be assigned on **Wednesday**.
- **Time & Platform:** Official weekly review meeting will be held on **Sunday morning, 09:00** via Discord.
- **PR Deadline:** Code must be pushed and Pull Requests (PRs) opened before **12:00 (Noon) on Saturday** to be counted for the current week. Late commits and PRs will count toward the following week.
- **Contingency Plan:** If a member cannot meet a deadline due to unexpected circumstances, they must notify the team as soon as possible (at least before Wednesday) for task reallocation.

## 4. Code and Documentation Standards

_Performed by: [Lê Công Minh Nhựt], Reviewed by: [Mai Đăng Khoa, Thái Hoàng, Nguyễn Khánh Đăng, Nguyễn Thanh Huy], Edited by: [Lê Công Minh Nhựt]_

- **Documentation:** All project documents must be written in English using Markdown format. Diagrams will be drawn using Mermaid syntax.
- **AI Tools:** The team will use educational AI tools (Gemini, ChatGPT, Claude) to assist with coding and problem-solving. Members must thoroughly explain any AI-generated code they submit.
- **Commit Minimums:** At least **5 meaningful commits** (following Conventional Commits) and at least **1 PR opened / 1 PR reviewed** per week.
- **Security:** NEVER commit `.env`, `credentials.json`, API keys, or secrets.

## 5. Accountability and Performance

_Performed by: [Lê Công Minh Nhựt], Reviewed by: [Mai Đăng Khoa, Thái Hoàng, Nguyễn Khánh Đăng, Nguyễn Thanh Huy], Edited by: [Lê Công Minh Nhựt]_

All tasks must be logged in Jira with creation, assignment, and real-time completion dates (no shared tasks).

**Team Disciplinary & Grading Policy:**

- **Meeting Participation:** Active participation is mandatory. Joining a Discord meeting but remaining completely silent with no contribution counts as an absence (0% for that session).
- **Lateness Penalty:** A maximum 10-minute grace period is allowed. From the 11th minute, **1% is deducted** from that session's score for every minute late.
- **Late Deadline Penalty System:**
  - _1st Offense:_ Formal warning. The member must complete the overdue task immediately and take on additional compensation tasks.
  - _2nd Offense onwards:_ A strict **-10% deduction** from the member's _final overall project contribution score_ per late deadline.
  - _3rd Offense:_ The team will convene to decide on severe actions, which may include reporting to the Instructor/TA.
- **Final Contribution Calculation:**
  The final score is the arithmetic mean of all individual meeting scores, minus overall late penalties.
  _(Example: 5 meetings scored 90%, 80%, 100%, 100%, 90% + 2 late deadlines triggering the -10% penalty. Calculation: `((0.9+0.8+1.0+1.0+0.9)/5) - 0.10 = 0.82 (82%)`. Rounded to 85%.)_
